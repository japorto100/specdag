# Generated Artifacts Guidance

Generated artifacts are outputs of `specdag`. They are useful for review, agent context, impact analysis, and visual inspection, but they are not source of truth.

## Recommended folder

```text
specs/
  _generated/
    README.md
    dependency-map.global.json
    dependency-map.global.yaml
    dependency-map.global.mmd
    dependency-report.html
```

## Rules

- Do not edit generated files manually.
- Regenerate them from local maps with `specdag`.
- Generated artifacts may be committed when they help reviews, audits, or agent context.
- Generated artifacts may be excluded from Git if they are noisy and reproducible in CI.
- If a generated artifact disagrees with a local feature map, the local map wins.
- If a generated artifact reveals a conflict, fix the local source map, catalog, or contract.

## Suggested commands

```bash
specdag assemble specs/features/ -o specs/_generated/dependency-map.global.json
specdag assemble specs/features/ --format yaml -o specs/_generated/dependency-map.global.yaml
specdag render specs/_generated/dependency-map.global.json -o specs/_generated/dependency-map.global.mmd
specdag report specs/features/ -o specs/_generated/dependency-report.html
```

## Header for generated files

```text
Generated by specdag. Do not edit manually.
Source: specs/features/*/dependency-map.yaml
Durable truth: domains/, events/, contracts/, foundations/
```
