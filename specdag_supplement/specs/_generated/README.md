# Generated Spec Artifacts

This folder contains artifacts generated by `specdag`.

Do not edit these files manually.

Source of truth:

- `specs/features/*/dependency-map.yaml`
- `specs/domains/`
- `specs/events/`
- `specs/contracts/`
- `specs/foundations/`

Typical generated files:

```text
dependency-map.global.json
dependency-map.global.yaml
dependency-map.global.mmd
dependency-report.html
```

Regenerate with:

```bash
specdag assemble specs/features/ -o specs/_generated/dependency-map.global.json
specdag report specs/features/ -o specs/_generated/dependency-report.html
```
